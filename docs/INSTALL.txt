Click2Screen - запись экрана и снимки экрана для Windows 10/11
==============================================================

1. Установка
   - Запустите Click2Screen-Setup.exe (попросит права администратора). Он сам выберет 64- или 32-разрядный установщик.
   - По желанию: «Ярлык на рабочем столе», «Ярлык в меню Пуск», «Запускать вместе с Windows (в трее)».
   - Нажмите «Установить» («Обновить», если уже установлено). Программа попадёт в
     C:\Program Files\Click2Screen\ и появится в Параметры > Приложения. «Запустить» откроет её.
   - Для скриптов: Click2Screen-Setup.exe /install /silent [/autostart] [/desktop-] [/startmenu-]
     (код возврата 0 - успешно).

2. Первое использование
   - Горячие клавиши: Ctrl+PrintScreen - снимок всего рабочего стола, Alt+Shift+4 - области, Alt+Shift+5 - окна,
     F11 - остановить запись. Кнопки главного окна делают то же самое.
   - Запись: «Запись рабочего стола / области / окна», затем «Старт» в маленькой панели (если в настройках задана
     задержка, сначала идёт обратный отсчёт). Повторное нажатие - пауза, «Стоп» (F11) сохраняет MP4 в папку «Видео».
   - Если закрыть окно, программа остаётся в трее («Выход» в меню значка закрывает её).

3. Удаление
   - Click2Screen-Setup.exe > «Удалить» или uninstall.cmd от имени администратора. Настройки, снимки и видео
     сохраняются.

4. Журналы
   - C:\ProgramData\Click2Screen\logs\ : setup.log (установщик), panel.log (программа).
